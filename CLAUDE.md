# IAMS-mobile

Flutter mobile client for the Inventory and Asset Management System. Dart.

**State management: inspect before assuming.** This repo is currently an empty scaffold (only
`LICENSE`/`README.md`), so there is no existing convention yet. Whichever approach the first real
feature establishes (Bloc, Cubit, Riverpod, Provider, GetX, `ChangeNotifier`, or otherwise) becomes
the convention — do not introduce a second, competing state-management framework alongside it
later.

See the workspace-level `../CLAUDE.md` for the Agent Teams setup this repo is part of.
